# 禅阅音频母带工匠技能规范 (Zen Audio Master SOP)

本技能定义了《禅阅》全藏经文从“纯净文本”到“双音色母带”及“毫秒级字句高亮同步”的标准工业级全生命周期管线。彻底根绝“临时打补丁”式的反复翻车。

---

## 核心失效根因与三大红线禁令

### 🔴 禁令一：严禁使用生造同音字替换（破坏大模型语义）
- **错误做法**：为了纠音，将《心经》替换为“波惹、萨朵、形识、无明进、萨婆呵”。
- **病根**：大模型 TTS 是语义驱动的。生造词导致模型误判为现代错乱文本，引发共鸣腔上浮、语气发飘、乱断句、吞字，导致声线彻底失真。
- **正解**：保持经文严谨原文。通过专门的诵经角色 System Instruction 与音素拼音引导词典，或者带调拼音注入，绝不破坏词性与语义结构。

### 🔴 禁令二：严禁行末无标点盲拼（导致断句窒息）
- **错误做法**：将 JSON 中的短行简单使用 "".join(lines) 拼接。
- **病根**：佛经多为四言、六言骈体。没有显式停顿标记时，大模型会一口气抢读多行，或在词语中间随意换气。
- **正解**：经文必须经过气口重构器（Breathing Formatter），短句尾部注入显式微停顿符号（如逗号、破折号或 200~300ms 韵律气口），确保四六骈俪呼吸均匀。

### 🔴 禁令五：严禁在紧凑名相内部滥加停顿符号（导致意群断层空悬）
- **错误做法**：为了纠音或防粘连，在名相内部插入逗号（如“波惹，波罗蜜多”或“菩提，萨朵”）。
- **病根**：TTS 模型会将逗号、空格或破折号解析为强制换气休止符，制造长达 400ms~800ms 的无声断崖，破坏诵经整体心流。
- **正解**：专有名相内部绝对禁止插入任何断句标点，保持字字相扣、气断声不断（字间隔控制在 80ms~120ms 内）。通过“前置注音指示 + 纯净正音汉字替换（如波惹波罗蜜多、受想形石、菩提萨朵）”自然连贯发音。

## 工业级母带生成五步流水线

### 步骤 1：篇幅容量与调用分级 (Payload & Quota Architecture)
1. **短篇与独立品（≤ 400 汉字，如《心经》全篇、金刚经绝大多数单品）**：
   - **绝对强制单次直出（Single-Pass）**：严禁人为拆分为多个小分部；
   - **配额守恒法则**：单篇经卷调用次数严格锁死为 **2 次**（莲华女声 1 次 + 暮钟男声 1 次），杜绝消耗单日额度；
   - 90~120 秒音频单次生成气韵连贯、浑然天成，零拼接缝隙。
2. **超长章节（> 400 汉字，如极个别万字长卷）**：
   - 仅在超出模型单次上下文音频上限时，才允许按自然章回/义理段落进行大块切分，且切片必须本地持久化为 PCM 断点缓存。

### 步骤 2：气口微顿与音素规范化 (Text & Pacing Normalization)
1. **开篇品题**：经文显式包含品题并留出 500ms~600ms 入静微顿（如：“般若波罗蜜多心经。 —— ”）。
2. **四六气口**：每行短句尾部规范化为平声休止符（200~300ms），严禁疑问句尾音挑起（如“耶？”强制转为平稳“耶。”）。
3. **名相内部零空隙**：名相内部保持自然语流（80~120ms），底本严禁在“波惹”或“萨朵”后出现逗号。
4. **尊经与底本分层**：
   - **展示层（JSON）**：100% 保持古籍原汉字尊严与官方标准注音（如“般若 rě”、“受想行识 shí”、“菩提萨埵 duǒ”）；
   - **诵读层（Prompt底本）**：依据总账字典（`buddhist_dict.py`）编译为防降调正音文本（如“波惹波罗蜜多”、“受想形石”、“菩提萨朵”），彻底解脱大模型概率失真。

### 步骤 3：声学演员指纹锁定 (Voice & Timbre Locking)
1. **音色矩阵**：
   - 莲华女声：Gemini Zephyr
   - 暮钟男声：Gemini Charon
2. **System Prompt 角色定型**：
   - 提示词模板：
     ```text
     用平稳、自然、安详的普通话从容念诵以下经文。
     要求：声音平静安详、字音平直匀速、不带舞台朗诵腔、无情绪波动起伏，气息从容均匀，声断气不断。
     遇到经文古梵音与多音字，严格按注音指引念诵。
     ```
3. **参数锁死**：禁止开启任何人工 aecho 浴室混响，保持原始 24kHz 贴耳纯干声。经 FFmpeg `highpass=f=45,volume=1.05` 滤除低频共振。

### 步骤 4：Whisper 全局音素级强制对齐 (Global Forced Alignment)
1. 单次母带直接送入 Whisper 提取全量词级/音素级物理时间戳；
2. 采用 `SequenceMatcher` 基于音素拼音锚点对齐，将真实发音的起始点与经文字符严格锁定；
3. 将字符物理时间回写到每行（`lineStart`/`lineEnd`）与每段（`startTime`/`endTime`），精度达 30ms 级别。

### 步骤 5：经文 JSON 单一真理源动态门禁 (Phonetic Consistency Audit)
1. **单一真理源铁律（Single Source of Truth）**：
   - 严禁任何凭直觉硬编码声调的行为！经文 JSON（`src/data/<book_id>/<chapter_id>.json`）中展示给读者的拼音，是发音审定的唯一最高法典。
2. **生成后真声学阻断断言**：音频生成后，Whisper ASR 提取音频实际发音字与声学音素。利用 `pypinyin` 分析 ASR 输出与 JSON 屏幕注音进行严格双向比对。
3. **红线拦截清单（PhoneticAuditError 阻断落盘）**：
   - **诸法空相 之【相】**：屏幕标注 `xiāng`（一声），严禁读四声 `xiàng`（象/向）；
   - **究竟涅槃 之【究】**：屏幕标注 `jiū`（一声），严禁读四声 `jiù`（就）；
   - **揭谛揭谛 之【揭】**：屏幕标注 `jiē`（一声），严禁读二声 `jié`（截）；
   - **阿耨多罗 之【耨】**：屏幕标注 `nuò/nòu`（四声鼻音），严禁读边音 `l/漏`；
   - **般若波罗蜜多 之【若】**：屏幕标注 `rě`（三声），严禁读四声 `ruò` 或元音低化 `ra/染`；
   - **受想行识 之【识】**：屏幕标注 `shí`（二声），严禁句末降调读四声 `shì`（事/是）；
   - **菩提萨埵 之【埵】**：屏幕标注 `duǒ`（三声），严禁读四声 `duò`（堕）或音素漂移；
   以上只要有 1 处不符，流水线立即中断并抛出 `PhoneticAuditError`，**严禁落盘发布为生产 MP3 和更新经文时间轴**！

### 步骤 6：全藏通用命令与闭环检查 (Universal CLI & Checklist)
全藏经文（包含《心经》全篇及《金刚经》32品等）统一执行标准化通用流水线：
```bash
# 生成单卷经文女声母带（严格通过全量声调真门禁）
python scripts/generate_sutra_master.py <book_id> <chapter_id> --voice female

# 生成单卷经文男声母带
python scripts/generate_sutra_master.py <book_id> <chapter_id> --voice male
```

每次生成后必须通过八项黄金检查：
- [ ] 篇幅架构：400字以内是否单次直出（全流程仅调 1~2 次 API）？
- [ ] 安全豁免：是否配置 `BLOCK_NONE` 彻底杜绝经文词汇误杀？
- [ ] 开篇品题：是否有清晰读题并留出充足入静停顿？
- [ ] 真理源一致性：音频发音是否 100% 绝对服从经文 JSON 屏幕注音（相xiāng、究jiū、揭jiē、耨nuò、若rě、识shí、埵duǒ）？
- [ ] 意群零空隙：名相内部（如“波惹波罗蜜多”）是否自然相扣，无 400ms+ 断崖真空？
- [ ] 声字门禁断言：Whisper ASR 识别音素声调是否 100% 通过红线断言，零警告放行？
- [ ] 声场音色：是否为贴耳纯干声，无人工浴室回声？
- [ ] 视觉同步：逐行播放时，文字高亮与声音是否严丝合缝？
