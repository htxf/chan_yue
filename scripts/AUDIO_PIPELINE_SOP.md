# 禅阅音频生成与经文同步标准作业程序 (Audio Pipeline SOP)

本文档固化了《禅阅》经文音频生成、多音字校准、双音色配置及物理时间轴同步的全部工程规范。后续所有章节生成必须严格执行本规范，绝不复犯历史错误。

---

## 一、 经文诵读风格与 Prompt 规范 (Purity & Style Standard)

* **核心原则**：佛经念诵必须**平实、淡然、无情感波澜、字音平直匀速、心如止水**。
* **严禁行为**：严禁加入“古典朗诵风格”、“沉稳有力”、“深情”等诱发舞台播音感、戏剧表演腔与刻意起伏的修饰词。
* **统一黄金 Prompt 模板**：
  ```text
  用平稳、自然、无修饰的普通话念读以下文字，语调平平、不带朗诵感：\n\n{text}
  ```
* **双音色标准配置**：
  * 🌸 **清平女声**：`gemini-3.1-flash-tts-preview` + `Zephyr`
  * 🪵 **沉稳男声**：`gemini-3.1-flash-tts-preview` + `Charon`
* **声学空间滤镜 (1.5x 古刹幽鸣)**：
  ```text
  highpass=f=70,equalizer=f=150:width_type=h:width=120:g=2.2,equalizer=f=10500:width_type=h:width=2500:g=2.8,aecho=0.80:0.75:80|160|260:0.22|0.12|0.06
  ```

---

## 二、 读音与屏幕注音 100% 强校验 (Pronunciation Dictionary)

* **核心原则**：音频朗诵的字音必须与页面经文的 `<rt>` 拼音注音保持 **100% 绝对一致**。
* **强制校准替换字典 (Sutra Phonetic Mapping)**：
  * 《心经》`波罗蜜多故` $\rightarrow$ `波罗蜜哆故` (强制 `duō` 一声，杜绝四声 `duò`)
  * 《心经》`菩提萨婆诃` $\rightarrow$ `菩提萨婆诃` (强制 `sà` 四声，杜绝传统唱诵 `suō`)
  * 《心经》`诸法空相` $\rightarrow$ `诸法空向` (`xiàng` 四声)
  * 《心经》`无明尽/老死尽` $\rightarrow$ `无明进/老死进` (`jìn` 四声)
  * 《心经》`得阿耨多罗` $\rightarrow$ `得阿漏多罗` (`nòu` 四声)
  * 《金刚经》`著衣持钵` $\rightarrow$ `浊衣持钵` (强制 `zhuó` 二声，杜绝 `zháo/zhao`)
  * 《金刚经》`一时` $\rightarrow$ `意时` (`yì` 四声)
  * 《金刚经》`祇树给孤独园` $\rightarrow$ `奇树几孤独园` (`qí / jǐ`)
  * 《金刚经》`千二百五十人` $\rightarrow$ 严格念读 `千二百五十人` (`èr bǎi`，绝不读成千两百)
  * 《金刚经》`饭食讫` $\rightarrow$ `饭食气` (`qì` 四声)
  * 《金刚经》`长老须菩提` $\rightarrow$ `掌老须菩提` (`zhǎng` 三声)
  * 《金刚经》`右膝着地` $\rightarrow$ `右膝浊地` (`zhuó` 二声)
  * 《金刚经》`愿乐欲闻` $\rightarrow$ `愿要欲闻` (`yào` 四声)
  * 《金刚经》`降伏其心` $\rightarrow$ `降服其心` (`xiáng fú`)

## 三、 时间轴与屏幕滚动同步标准 (Acoustic Burst Physical Alignment)

* **严禁行为**：严禁按纯字数线性均摊时间（经文前慢中快的呼吸节奏会导致中后段严重脱节）。
* **自动化生成标准流程**：
  1. 调用 TTS 合成音频并输出 192k MP3；
  2. 自动运行 **声学发声爆发段检测算法（Acoustic Speech Burst Detection）**，将音频波形的每一个发声爆发段与经文文本的每一行进行 **1 对 1 精准时间锚定**；
  3. 将毫秒级真实时间戳写入 JSON；
  4. 界面滚动仅在激活行向下变化时触发平滑滚动，在句间呼吸停顿期间保持视口平稳，杜绝上颠回滚。

## 四、 自动化执行脚本

生成新章节时，直接运行：
```bash
python scripts/generate_chapter_master.py <book_id> <chapter_id>
```
脚本将全自动完成双音色生成、字音强制校正、1.5x声学渲染及物理波形 1:1 时间戳对齐。
